AI Usage Log
Project: FNaF World Party Builder & Encyclopedia
Pathway: Full-Stack Web

Entry 1: Planning and organizing the website
AI assistance: I discussed my FNaF World project structure with the assistant in terms of what would be plausible, including the character gallery, team builder, and encyclopedia so I wouldn't be tacking on more than I could do. I also used the assistant to help organize my ideas and plan features of the site, such as where I could add certain elements like bubble effects, hover effects, and those sort of details/where they would fit most easily.
My work: I decided which features to include and how I wanted the website to function, including the party creation system and character filters.
Result: I established the website's main features and organized the React components and character data.

Entry 2: Frontend development and design
AI assistance: I used the assistant to help with React components, code organization, and troubleshooting errors along the way, as well as a basic modern layout for the site.
My work: I made several independent frontend adjustments, including improving page responsiveness, refining layouts, and adjusting the appearance and behavior of website elements including things like buttons, shading, organization, how many characters should be on each page, and so on. I also reviewed any tweaks that the assistant made and made changes based on how I wanted the site to look and function. 
Result: I developed a working frontend with a character gallery and party builder interface.

Entry 3: Backend & SQLite database
AI assistance: I used the assistant for help coding and trobleshooting while developing my FNaF World website's full-stack functionality.
My work: Although I was personally dissatisfied with the site's general aesthetic and front-end look, I knew logically I should make sure my site is just functioning as a full-stack project before I move onto revamping or anything. Thus, I worked on creating and setting up the backend and SQLite database, including database.cjs, index.cjs, test-database.cjs, and parties.db. I added the database structure for storing parties, worked on the backend functionality, and tested everything to make sure it worked.
Result: I established and tested the backend and SQLite database functionality before moving on to the Frutiger Aero redesign. This gave my website a functional foundation beyond just the React frontend.

Entry 4: Frutiger Aero redesign
AI assistance: The assistant helped with the original frontend foundation, which used a fairly generic modern layout with simple character cards. 
My work: After trying to get the assistant to make a foundation I wasn't dissatisfied with, I decided to change the entire visual direction of the website, to a Frutiger Aero-inspired design. I redesigned the interface with glossy and translucent panels, colorful gradients, a Frutiger Aero background provided by a person on Reddit who created it via Photoshop (*credit here), dimensional character badges, and more detailed character cards. I also adjsuted the filters, navigation, spacing, and responsive layouts to work with the new design.
Result: I transformed the website from a relatively simple card-based layout into a much more distinctive Frutiger Aero-inspired interface.

Entry 5: Character gallery and party builder
AI assistance: I discussed character data, filtering options, and party builder functionality with the assistant. The assistant helped with organizing features/ideas and troubleshooting code.
My work: I refined the party builder requirements, including selecting four characters per party, creating multiple parties, and displaying the saved parties. I also customized the character cards, their information, and the interface.
Result: I developed a character gallery and party builder that support the main purpose of my website.

Entry 6: Character encyclopedia development
AI assistance: I asked the assistant to collect information for encyclopedia entries of all 48 playable FNaF World characters, using my original Freddy entry as an example of what information I wanted to collect. AI produced character information organized into background, appearances, trivia, behind the scenes details, FNaF World info, and theories.
My work: I reviewed the content and found that many entries were too generic, formal, lacking in detail, or even just incorrect based on my own knowledge of the game's lore. I decided to start over with the character entries and write the info myself, using the AI-generated examples mainly as a reference for section structure and approximate length.
Result: I began rebuilding the encyclopedia content while maintaining a consistent format across character profiles.

Entry 7: Testing & troubleshooting
AI assistance: I used the assistant for help understanding code errors, troubleshooting issues, and reviewing parts of the website's structure.
My work: I tested the website's functionality, made frontend adjustments (bubble effects and color changes when a party is hovered over in Party Builder, as well as additional hover and coloring effects whenever other buttons were hovered over on the site, among other minor tweaks), and improved responsiveness across different screen sizes. 
Result: I resolved issues encountered during development and verified that the existing features worked as intended.

Entry 8: Capstone documentation
AI assistance: Understanding the milestone requirements for this capstone.
My work: I laid out this log and organized it in order of what I've been doing for the site so far, so all in all: I started out with the frontend, going with the minimalistic but functional design that the assistant largely provided, moved on to building a functional backend and linking them with a custom API to analyze parties, and only then redesigning the frontend to reflect the Frutiger Aero aesthetic. Then, I could work on the site structure, character encyclopedia, and testing the final product to make sure the site functions as intended.
Result: I created documentation that distinguishes plain old fully AI work from my independent development work.

Overall reflection:
I used the assistant for coding assistance, troubleshooting, organizing info, and generating examples throughout my project. However, I reviewed its output and made significant changes independently. I built and tested the backend and SQLite database before moving on to a major frontend redesign. I changed the website from a generic modern layout to a Frutiger Aero-inspired design and independently worked on responsiveness, layouts, and visual details. For the encyclopedia, I wasn't satisfied with the content that AI provided, so I started over and wrote the character entries myself. I used AI mainly as a reference for the structure and approximate length of each section, for the sake of speeding up the process. Overall, AI helped me with parts of the development process, but I made my own design decisions, implemented and tested functionality, and substantially customized the website.
